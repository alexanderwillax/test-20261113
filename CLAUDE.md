# Regeln für dieses Projekt

## Sprache
- Antworte immer auf Deutsch.
- Benutze einfache Sprache: kurze Sätze, wenig Fachwörter. Wenn ein Fachwort nötig ist, erkläre es kurz.

## Technik
- Benutze nur HTML, CSS und JavaScript.
- Keine externen Bibliotheken oder Frameworks (zum Beispiel kein jQuery, kein React, kein Bootstrap).
- Keine Dateien oder Skripte aus dem Internet einbinden (kein CDN).

## Sicherheit
- Schreibe niemals Passwörter, API-Schlüssel, Tokens oder andere Geheimnisse in Dateien.
